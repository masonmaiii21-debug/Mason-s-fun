# 玄鉴 · Mason Metaphysics Skill

一个多模态中国传统命理 Skill，整合：八字、紫微斗数、流年大运、合婚、择日、风水、面相、骨相外观观察与手相。

## 安装依赖
```bash
npm install
```

## ChatGPT Skill
本目录符合以 `SKILL.md` 为入口的 Agent Skills 结构，可整体压缩后在支持个人 Skills 的 ChatGPT 工作区中上传。

## 计算依赖
- `iztro`：紫微斗数排盘
- `lunar-javascript`：公农历、八字、十神、黄历/宜忌等

## 设计原则
可程序化的数据交给脚本；图像先观察再解释；不同传统体系只做交叉印证，不伪造科学准确率。
