# 多体系交叉印证规则

## 不做简单投票
不同体系并非独立科学测量，不能用“3 个体系都说一样，所以准确率 90%”之类算法。

## 主题矩阵
按主题汇总：性格/行为倾向、事业、财务、关系、迁移、学习、环境。

每条结论记录：
- 来源：八字 / 紫微 / 面相 / 手相 / 风水 / 择日
- 类型：计算数据 / 可见观察 / 传统解释
- 强度：强 / 中 / 弱
- 不确定性来源

## 一致
若多个传统体系指向相近主题，表述为“在不同传统框架中出现重复主题”，不要转化为科学置信概率。

## 冲突
保留冲突并解释可能原因：出生时间边界、流派差异、照片角度、不同体系关注维度不同。

## 最终结论
优先给用户可验证、可行动、低风险的现实建议。传统解释放在其后。
